# Brukerens tilbakemelding etter 1.0.0 (8. november 2026)

Brukeren testet 1.0.0 · bygg 16 installert og ba om dette til 1.1.0 · bygg 17. Sitatet er gjengitt med brukerens ord:

> Legg til så kan lese det i Agentic Rigg, kan lage egen side bare til disker, kan også se om er noe annet som kan høre til egen side, neste som kan legges til er Code Pro signatur i innstillinger, også er det noe feil med åpne lukke x og minimer knapper, akkurat som er sånn rar. Hmm, RTX 2080 i side panel trenger ikke sånn grønn prikk. ser det bedre ut hvis du legger til CPU eller mer der sånn som GPUen?, kan se på det og. Kan gjøre styring i side panel mer oversiktlig med hva det styrer gjelder også lys og vifte, kan lage siden mer overclock vennlig på designet, også med tilbakestilling standard m/ lettere å se ulike klokke hastigheter og temperatur og sånn. også mer info der hva gjør og styrer. styring: Kontroller og viftekurve bør redesignes er forbedring potensiale der.

Skjermbildet `vindusknapper-1.0.0.png` viser toppfeltet i mørkt tema: «1 min»-velgeren og minimer/maksimer/lukk som store, mørke, tunge sirkler der ikonene ser små og litt skjeve ut.

## Fordeling (hovedøkta)

| Agent | Eier |
|---|---|
| **6A Maskinvare** | Ny side **Disker** (UDisks2 over D-Bus uten root: modell, serie, fastvare, o/min, SMART-helse, temperatur, driftstid, hele SMART-tabellen, selvtest; `/proc/diskstats` for MB/s og aktivitet; ledig plass per partisjon). Ny side **Prosessor** (CPU-Z-delen som i dag ligger på System). **System** beholder hovedkort/BIOS, minne og operativsystem. Disktemperatur og -hastighet i Sensorer og Grafer, helsevarsel i varslene. |
| **6B Skall** | Vindusknappene, sidefeltet (enhetsvelgeren uten grønn prikk, CPU ved siden av GPU, tydeligere Styring-gruppe), tastene 1–9/0, Code Pro-signaturen i Innstillinger › Om. |
| **6C Styring** | Redesign av Kontroller og Viftekurve: overklokkingsvennlig, tilbakestill til standard, lett å se klokker og temperatur, forklaring av hva hver kontroll gjør. Fortsatt låst mot det ekte kortet. |
