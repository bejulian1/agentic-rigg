# Brukerens ønsker til 1.2.0 (9. november 2026)

Brukerens ord:

> Fint, kan også mulig legge til så enkelt å skru av og på root eller det trenger for å endre GPU klokker og lys / viftehastighet.
> Kan du se om er mulig å gjøre så kan stoppe viftene ved en gitt temperatur i kurve mot viftehastighet, hvor fleksibelt gpu vifter er. Hmm? pga på msi afterburner har ganske fleksibelt kurver og sånn vet ikke om funker gjøre noe lignende her.

Brukeren svarte senere at 1.2.0 skal ha begge delene, og at 1.1.0 ikke skal installeres ennå.

## Svar og avgrensning (hovedøkta)

- **Viftestopp (0 %) er ikke mulig på dette kortet.** VBIOS har minimum 35 %, målt med NVML `GetMinMaxFanSpeed` = 35–100 %. Driveren nekter alt under 35 %, og det gjør Afterburner også på NVIDIA-kort. Vi skal ikke flashe VBIOS. Det vi kan gi, er Afterburner-fleksibilitet: flere punkter, hysterese, rampefart, egen kurve per vifte og en «stille» flate på 35 % opp til en valgt temperatur.
- **Bryteren for endring** bygges i trinn. Hvert trinn mot det ekte kortet krever brukerens eget ja, hver gang.
  1. **1.2.0:** bryteren og root-hjelperen er bygget og testet bare mot det simulerte kortet. Ingen skriving til det ekte kortet. Ingen pkexec, sudo eller systeminstallasjon kjøres av agenter.
  2. **Senere:** effektgrense.
  3. **Senere:** vifter.
  4. **Senere:** klokke-offset.
  5. **Senere:** RGB, med en lesende I2C-sjekk først.
